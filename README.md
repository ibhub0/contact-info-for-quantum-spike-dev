This repository contains a minimal, professional static website that displays contact information and includes a dark/light theme toggle.

- Simple **mailto** link for the email address.
- Direct links to two Telegram accounts.
- Dark / Light theme toggle that remembers the user preference.
- Responsive, pure‑HTML/CSS/JS (no build step required).

## How to Deploy to GitHub Pages
1. **Create a new repository** on GitHub (e.g., `my-contact-info`).
2. Clone the repository locally:
   ```bash
   git clone https://github.com/<your‑username>/my-contact-info.git
   cd my-contact-info
   ```
3. Copy the `index.html` (and this `README.md`) into the repository root.
4. Commit and push:
   ```bash
   git add .
   git commit -m "Add contact page with theme toggle"
   git push origin main
   ```
5. In the GitHub repository settings, enable **GitHub Pages**:
   - Source: **main** branch
   - Folder: **/(root)**
   - Save.

GitHub will automatically publish the site at:
```
https://<your‑username>.github.io/<repo-name>/
```
